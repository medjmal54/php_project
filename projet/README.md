# Hiking Management System - Complete Enterprise Solution

A production-ready, fully-featured hiking trip management platform built with clean PHP code and professional architecture.

**🎯 Perfect for:** Adventure tour operators, travel companies, tourist organizations, outdoor clubs, and adventure activity providers.

---

## ⚡ Quick Start (5 minutes)

1. Extract to web server root
2. Import `database.sql` via phpMyAdmin
3. Update `config/db.php` with your credentials
4. Set permissions: `chmod 755 public/uploads`
5. Access: `http://localhost/projet`
6. Login: `admin@randonnee.tn` / `password`

**See [QUICK_START.md](QUICK_START.md) for detailed instructions.**
